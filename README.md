# Advanced Computer Vision

## Overview

This repository contains my Advanced Computer Vision project, completed as part of my postgraduate studies in Artificial Intelligence.

The project explores practical computer vision techniques through implementation, experimentation, evaluation, and development logging.

## Project Objectives

- Apply computer vision and image-processing techniques.
- Experiment with different model and training configurations.
- Evaluate the effect of different parameters on performance.
- Document the development and experimentation process.
- Analyse and present the results.

## Technologies & Concepts

- Python
- Computer Vision
- Image Processing
- Machine Learning
- Deep Learning
- Model Training
- Model Evaluation
- Image Analysis
